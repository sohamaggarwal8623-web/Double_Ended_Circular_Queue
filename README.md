Double Ended Queue (Deque) Implementation in C

A simple implementation of a Double Ended Queue (Deque) using arrays in C.

This project demonstrates:

Insertion from front
Insertion from end
Deletion from front
Deletion from end
Queue traversal
Features

✅ End Enqueue
✅ Front Enqueue
✅ End Dequeue
✅ Front Dequeue
✅ Queue Printing
✅ Dynamic Memory Allocation using malloc
